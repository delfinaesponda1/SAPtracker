📁 Working Directory — The Key Concept
📁 Directorio de Trabajo — El Concepto Clave

The single folder Joule can access on your computer. Acts as a sandbox — Joule cannot read or write anything outside this boundary. Your Desktop, Documents, and other folders remain completely untouched unless explicitly added.

La única carpeta a la que Joule puede acceder. Funciona como un sandbox — no puede leer ni escribir nada fuera de ese límite. Tu Escritorio, Documentos y otras carpetas quedan intactos.

Connectors — Connect Live to External Systems

Conectores — Conexión en Vivo con Sistemas Externos

A Connector gives Joule the ability to read or act on an external system during a conversation.
Un Conector le da a Joule la capacidad de leer o actuar sobre un sistema externo durante una conversación.
What is a Connector?
¿Qué es un Conector?

A live integration between Joule Work Desktop and an external system — SharePoint, a database, Jira, SAP systems. Under the hood, it uses the Model Context Protocol (MCP) — an open standard for AI assistants to communicate securely with external services.

Una integración en vivo entre Joule Work Desktop y un sistema externo — SharePoint, una base de datos, Jira, sistemas SAP. Por dentro, usa el Model Context Protocol (MCP) — un estándar abierto para que los asistentes de IA se comuniquen de forma segura con servicios externos.

❌Without a ConnectorSin un Conector

Joule cannot access live internal data. Ask for Q3 revenue without a Connector, and Joule will tell you it cannot access that data — it only knows what you tell it in the prompt.

Joule no puede acceder a datos internos en vivo. Preguntá por revenue del Q3 sin un Conector, y Joule te dirá que no tiene acceso — solo sabe lo que le decís en el prompt.

✅With a ConnectorCon un Conector

Joule can query the connected system directly and return live data — tables, charts, or summaries from real-time information. Examples: Jira issues, SharePoint documents, SAP system data.

Joule puede consultar el sistema conectado directamente y devolver datos en vivo — tablas, gráficos o resúmenes en tiempo real. Ejemplos: issues Jira, documentos SharePoint, datos SAP.

Skills — Teach Joule Your Workflows

Skills — Enseñale tus Flujos de Trabajo a Joule

Skills are reusable instruction sets — playbooks Joule follows automatically when triggered.
Los Skills son conjuntos de instrucciones reutilizables — playbooks que Joule sigue automáticamente al activarse.

Once created, Joule follows a Skill automatically when triggered. Skills eliminate repetitive prompting — define the workflow once and reuse it indefinitely. A Skill can use Connectors, read local files, search the web, and chain multiple steps.

Local-first, privacy-preserving. Here is exactly how your data is protected at every layer.
Local-first, preservación de privacidad. Así se protegen tus datos en cada capa.
🔐 AES-256 Local Encryption
All conversations are stored on your device in an AES-256 encrypted database. The encryption key is in your OS keychain — never in plain text.
Todas las conversaciones se almacenan en tu dispositivo en una base de datos encriptada AES-256. La clave está en el keychain del SO — nunca en texto plano.
📁 Sandboxed File Access
Joule can only access files inside your designated working directory. It cannot read, write, or list files outside this boundary — your Desktop and Documents are untouched.
Joule solo puede acceder a archivos dentro de tu directorio de trabajo. No puede leer, escribir ni listar archivos fuera de ese límite.
🎤 On-Device Voice Processing
All speech-to-text happens locally (~466 MB model). Audio is never transmitted anywhere — not to SAP, not to Anthropic, not anywhere.
Todo el reconocimiento de voz ocurre localmente (~466 MB de modelo). El audio nunca se transmite a ningún lugar — ni a SAP, ni a Anthropic.
🔑 Secure Token Storage
OAuth tokens (Microsoft 365, MCP) and API credentials are stored using OS-level secure storage — never in plain-text files or logs.
Los tokens OAuth y credenciales API se almacenan en el almacenamiento seguro del SO — nunca en archivos de texto plano o logs.
✅ Approval-Gated Actions
Joule always asks for your explicit approval before writing files or executing commands. You see exactly what will happen before confirming — every single time.
Joule siempre pide tu aprobación explícita antes de escribir archivos o ejecutar comandos. Ves exactamente qué va a pasar antes de confirmar.
🌐 AI Routing via SAP AI Core
Only conversation messages and context are sent to the AI model — routed through SAP AI Core. No files, tokens, passwords, or audio are ever transmitted.
Solo los mensajes y contexto de la conversación se envían al modelo de IA — via SAP AI Core. Ningún archivo, token, contraseña o audio se transmite jamás.

🤖 What about the AI models processing my prompts?
🤖 ¿Qué pasa con los modelos de IA que procesan mis prompts?
Your prompt is routed through SAP AI Core — SAP's managed AI infrastructure — where it is processed by the AI model. The underlying models are managed by SAP and selected to meet SAP's enterprise security and data protection standards.
Tu prompt se enruta a través de SAP AI Core — la infraestructura de IA gestionada por SAP — donde es procesado por el modelo. Los modelos son gestionados por SAP y seleccionados para cumplir los estándares empresariales de seguridad y protección de datos.

Sí — es técnicamente necesario porque ahí corren los modelos. Sin embargo, el procesamiento ocurre via acceso empresarial contractualmente asegurado, no instancias públicas. Tus datos están aislados, el uso para entrenamiento está contractualmente prohibido, y los proveedores están vinculados por Acuerdos de Procesamiento de Datos (DPAs).
